# snowflake-challenges

Hands-on Snowflake practice — [Frosty Friday](https://frostyfriday.org/) weekly challenges and lab work: SQL, data loading, Streams & Tasks, Time Travel, Cortex AI.

Every solution is a single self-contained `.sql` file: challenge setup + solution. Clone it, paste it into a Snowsight worksheet, and it runs end to end — no external accounts or data files needed.

## Running a solution

- **Snowsight:** paste the file into a worksheet and run all statements.
- **Snowflake CLI:** `snow sql -f sql_query_techniques/week_013/solution.sql`
- Any Snowflake account works — a [free trial](https://signup.snowflake.com/) is enough.

## About Frosty Friday

[Frosty Friday](https://frostyfriday.org/) publishes weekly community challenges to practice Snowflake skills. Challenges and datasets belong to their authors — this repo contains only my solutions.
